## About

I build end-to-end AI systems: extraction, normalisation, rule engines, and the interfaces that make model output reviewable.

- **The model extracts. Deterministic code decides.** A model reads the messy input. Rules you can read, test and trace make the call.
- **Honest ML.** Measured limitations over accuracy claims, traceable rules over model opinions, and labelled sample data.
- **Architecture to deployment.** I take AI products from first design through to production on my own.

<details>
<summary><b>Currently working on</b></summary>
<br>

- AI-native applications where a model extracts and deterministic code decides
- Document intelligence pipelines: PDF and image in, structured and auditable output out
- Agentic developer tooling and multi-agent build pipelines
- Geospatial, voice and multilingual interfaces for real-world workflows

</details>
